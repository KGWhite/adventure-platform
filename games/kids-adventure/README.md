# Kids Adventure (`games/kids-adventure`)

本目錄為 Adventure Platform 首個落地應用案例（Use Case / MVP 原型）：**兒童冒險與獎勵系統**。

## 專案定位
- **定位**：作為通用型實體 RPG 平台（Physical RPG Platform）的概念驗證（Proof of Concept）與輕量化實踐。
- **目標場景**：適用於家庭、安親班、學校或教育營隊，透過公會任務、實體憑證蓋章／感應（Adventure ID）與成就功績（Merit），將日常生活習慣或學習任務轉化為沉浸式 RPG 體驗。
- **架構關聯**：依託於平台通用之 `Player + World Node + Interaction + Rule` 核心架構，作為首個預設遊戲設定檔（Preset）。
